# Libya Dev API v0.2.0 🇱🇾

**v0.2.0 expands Libya Dev API from core location/phone primitives into source-backed business and calendar infrastructure for Libyan developers.**

## New: Libyan Banks API

The release adds a commercial-bank directory based on the **Central Bank of Libya** commercial-banks directory, checked on 2026-09-07.

- 26 bank records
- stable slugs
- Arabic and English names
- head-office city metadata
- official/published website
- Arabic/English search
- city filtering
- source metadata in API responses

### Endpoints

```text
GET /api/v1/banks
GET /api/v1/banks/{slug}
```

Examples:

```text
GET /api/v1/banks?q=النوران
GET /api/v1/banks?q=Jumhouria
GET /api/v1/banks?city=Benghazi
```

The API does not invent SWIFT/BIC, IBAN, routing, branch or licensing details that are not present in the maintained source.

## New: Libya Official Holidays API

The holiday module uses **Law No. 5 of 2012 on Official Holidays** as its legal baseline.

It exposes fixed statutory holidays and separates them from religious holidays that require annual date confirmation.

For 2026, the calendar includes sourced confirmations for:

- February 17 Revolution Day
- Eid al-Fitr (3 statutory days)
- Labour Day
- Day of Arafah
- Eid al-Adha (3 statutory days)
- Hijri New Year
- Prophet Muhammad's Birthday
- the fixed statutory dates for Martyrs Day, Liberation Day and Independence Day

### Endpoints

```text
GET /api/v1/holidays
GET /api/v1/holidays/{year}
```

Holiday records explicitly identify their confidence/status:

- `confirmed_official_decision`
- `statutory_fixed_date`
- `requires_annual_confirmation`

For a future year where a religious date has not been officially confirmed, its date is returned as `null` rather than guessed from an astronomical or third-party calendar.

The API also does not infer substitute holidays, bridge leave or extra administrative leave without a source.
