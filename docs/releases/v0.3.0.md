# Libya Dev API v0.3.0 🇱🇾

**v0.3.0 adds live official Central Bank of Libya exchange rates, currency conversion, and public-sector business-day helpers.**

## New: Official CBL Exchange Rates

Rates are read from the Central Bank of Libya official exchange-rate page and returned with source metadata.

```text
GET /api/v1/exchange-rates
GET /api/v1/exchange-rates/{currency}
POST /api/v1/currency/convert
```

The API preserves the CBL published quote unit and also exposes normalized per-unit buy, sell and average values. This matters for rows that quote 10 or 100 units.

The exchange-rate layer includes cache-backed last-good fallback with explicit stale metadata if the upstream source is temporarily unavailable.

Currency conversion supports `average`, `buy`, or `sell` rate columns and treats LYD as the base currency. Conversion is mathematical only; it does not represent transaction eligibility, fees or settlement rules.

## New: Libya Business Calendar

```text
GET /api/v1/calendar/is-business-day?date=2026-09-10
GET /api/v1/calendar/next-business-day?date=2026-09-10
GET /api/v1/calendar/business-days?from=2026-09-01&to=2026-09-30
```

The business-day model combines:

- Sunday–Thursday public-sector workweek
- Friday/Saturday weekly rest
- official-holiday data already exposed by Libya Dev API
- explicit confidence metadata when future floating religious holidays are not yet officially confirmed

The range endpoint is inclusive and bounded to 366 days.
