# Libya Dev API v0.1.0 🇱🇾

The first stable public release of **Libya Dev API** — an API-first Laravel project that exposes reusable Libya-specific developer primitives over standard HTTP/JSON, so applications in any language or framework can integrate them.

## Included in v0.1.0

- Laravel 13 / PHP 8.3+
- versioned `/api/v1` interface
- Libya metadata endpoint
- municipalities and cities backed by the pinned `Libya Locations v1.2.0` release
- Arabic / English / slug location search
- Libyan mobile normalization from local, `+218`, `218` and `00218` forms
- mobile format validation and known-prefix classification
- telecom operator metadata with explicit source URLs and verification strength
- OpenAPI 3.1 contract at `/openapi.json`
- interactive Swagger UI at `/docs`
- public CORS, cache-backed source retrieval and API rate limiting
- structured `503 source_unavailable` responses when the pinned location source cannot be loaded
- Arabic and English project documentation
- reproducible dependencies through committed `composer.lock`
- GitHub Actions quality gate with PHPUnit and Laravel Pint

## Data integrity principle

Libya-specific facts are source-backed. Where evidence is weaker or historical, the API exposes that verification strength instead of presenting all records as equally authoritative.

Operator-prefix detection is reference metadata only. It is not a live subscriber, SIM ownership, routing, or mobile-number-portability lookup.

## Main endpoints

```text
GET  /api/v1/meta
GET  /api/v1/locations/municipalities
GET  /api/v1/locations/municipalities/{slug}
GET  /api/v1/locations/cities
POST /api/v1/phone/normalize
POST /api/v1/phone/validate
GET  /api/v1/telecom/operators
GET  /openapi.json
GET  /docs
```
