# Libya Dev API v0.4.0 🇱🇾

**v0.4.0 adds map-ready Geo helpers and tested source SDKs for JavaScript, Python and Dart/Flutter.**

## New: Geo API

The Geo layer reuses the pinned `Libya Locations v1.2.0` municipality point dataset and GeoJSON. It does not create or guess new coordinates.

```text
GET /api/v1/geo/municipality-points
GET /api/v1/geo/municipalities.geojson
GET /api/v1/geo/nearest?lat=32.8872&lng=13.1913&limit=5
GET /api/v1/geo/nearby?lat=32.8872&lng=13.1913&radius_km=50&limit=20
```

The points endpoint reports total/mapped coverage. `?mapped_only=1` removes records whose coordinates remain intentionally null.

Nearest and nearby queries use the Haversine formula and return straight-line reference distance in kilometers. They do not represent road routing or legal municipality-boundary containment.

## New: JavaScript SDK

Source: `sdks/javascript`

- zero runtime dependencies
- Node 18+
- wrappers for all current API modules

- Node test suite in GitHub Actions

## New: Python SDK

Source: `sdks/python`

- Python 3.9+
- standard-library HTTP implementation
- injectable transport for tests/custom clients
- wrappers for all current API modules
- unittest coverage in GitHub Actions

## New: Dart / Flutter SDK

Source: `sdks/dart`

- Dart 3.3+
- `http` client dependency
- injectable HTTP client
- wrappers for all current API modules
- `dart analyze` + `dart test` in GitHub Actions

## Package publication status

The SDKs are source packages in this release. **v0.4.0 does not claim publication to npm, PyPI or pub.dev.** Tagged GitHub source installation is documented in `sdks/README.md`; registry publishing will be handled separately once package ownership/release automation is set up.
