# Contributing

Contributions are welcome, especially from Libyan developers.

For Libya-specific data changes:

1. Include a reliable source URL.
2. State when you checked it.
3. Prefer current primary/official sources.
4. Do not fill gaps by guessing.
5. Add or update tests when behavior changes.

Before opening a pull request:

```bash
php artisan test
vendor/bin/pint --test
```
